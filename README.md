## 📌 Overview

This project implements two independent AI text detection pipelines:

| Approach | Method | AUC | Accuracy |
|---|---|---|---|
| 🌳 Decision Tree | 16 stylometric features + custom DT | 0.8882 | 79.01% |
| 🧠 MLP / ANN | BERT embeddings → PCA → MLP | 0.9751 | 91.78% |

Both models are trained on the [MAGE dataset](https://huggingface.co/datasets/yaful/MAGE) (170k samples, balanced human/AI).

## 🧠 Approaches

### 🌳 Decision Tree — Stylometric Analysis

A fully **from-scratch** Decision Tree implementation (no sklearn tree classes) trained on 16 hand-crafted linguistic features:

- **Hapax ratio** — fraction of words appearing exactly once
- **Type-Token Ratio (TTR)** — vocabulary richness
- **Sentence burstiness** — irregularity in sentence rhythm
- **Transition density** — overuse of discourse connectors
- **Passive voice ratio**, **polysyllabic ratio**, **contraction rate**, and more

> Threshold: 0.70 · Criterion: Gini · Max depth: 15

---

### 🧠 MLP / ANN — BERT Embeddings

A deep learning pipeline using semantic embeddings:

```
Raw Text → BERT (768-dim) → PCA (80-dim) → StandardScaler → MLP → Label
```

- **BERT**: `bert-base-uncased` extracts contextual [CLS] token embeddings
- **PCA**: reduces 768 dimensions to 80 for efficient classification
- **MLP**: 256 → 128 → 64 architecture with ReLU activations
- **5-fold CV AUC**: 0.9751 ± 0.0008

## 🚀 Run Locally

### 1. Clone the repo

```bash
git clone https://github.com/Arham8bit/AI-text-detection.git
cd AI-text-detection
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the combined web app

```bash
streamlit run app.py
```

### Or run individual GUIs

```bash
# Decision Tree
cd DT && streamlit run dt_gui.py

# MLP / ANN
cd MLP && streamlit run ann_gui.py
```
